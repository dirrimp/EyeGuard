## 4. Recommendations
- Keep the anon check at major: in-place `create or replace` keeps existing grants, so it over-flags those.
- Router `pkill` / child-process cleanup: candidate rule EG-OPS-07 for the next round, judgment only.
- No rule is retired yet. This replay ran the mechanical pass plus an escape trace; the per-rule judgment
  pass (model reviewing every diff against all 18 rules) was not run, so zero hits on a judgment rule here is
  not evidence that it never catches anything.
